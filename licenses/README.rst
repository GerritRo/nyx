Licenses
========

This directory holds license and credit information for the package and for
the third-party datasets it uses.

- ``LICENSE.rst`` — the BSD-3-Clause license that covers the nyx source code.
  This is the license referenced by the badge in the top-level ``README.md``.
- ``DATA.rst`` — provenance, citations, and usage terms for every scientific
  dataset that nyx bundles or downloads at runtime. These datasets are not
  covered by the package license and must be credited separately.
